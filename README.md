# Bike Sales Analysis - Excel

## 📌 Project Overview

This project analysis bike sales data using Microsoft Excel to identify customer 
purchasing patterns and generate  meaningful business insights.

## 🔨 Tools Used

- Microsoft Excel
- Pivot Tables
- Pivot Charts
- Excel Formulas
- Data Cleaning
- Data Visualization
- Dashboard Design

## 📊 Project Objectives

- Clean and prepare the dataset
- Analyse customer demographics
- Identify factors associated with bike purchases
- Create Pivot Tables and Pivot Charts
- Develop interactive Excel dashboard
- Present insights in a clear and visual format

## 📈 Dashboard

The project includes an interactive Excel dashboard that allows
users to explore the data using filters and visualization

## 💡 Key Skills Demonstrated

- Data cleaning
- Exploratory data analysis
- Data visualization
- Excel analytics
- Dashboard development
- Business insights
